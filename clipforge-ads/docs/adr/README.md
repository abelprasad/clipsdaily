# Architecture Decision Log — ClipForge Ads

ADRs for the `clipforge-ads/` Remotion project. Same rules as the main
repo's log (`docs/adr/README.md`): one decision per file, Nygard
template (Title, Status, Context, Decision, Consequences), filenames
are present-tense imperative verb phrases, lowercase with dashes.
ADRs are immutable — a changed decision gets a NEW ADR that supersedes
the old one.
